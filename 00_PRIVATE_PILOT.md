# Личный Windows Pilot — исходники отдельного репозитория

Создайте пустой **Private** репозиторий `smartmaktab-windows-pilot`. Распакуйте содержимое этого ZIP в его корень, сохранив `.github/workflows/`. Исходный публичный `smartmaktab` не меняйте. В этом ZIP только один workflow: личный неподписанный Windows Pilot. Не переносите в новый репозиторий ключ Android и его секреты. Не публикуйте пилотный EXE для школ.

Подробности: `WINDOWS_PILOT.md`. Если хотите проверить только установку, дополнительные Variables не нужны. Запуск: `Actions → SmartMaktab — личный Windows Pilot (без подписи) → Run workflow → confirm_unsigned: UNSIGNED`.
