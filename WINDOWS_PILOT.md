# SmartMaktab: личный Windows Pilot

**Это неподписанный Windows EXE для личной проверки**, не официальный релиз для школ. Windows может предупредить или заблокировать запуск. Не отключайте защиту Windows и не распространяйте данный установщик пользователям. В APK ничего не добавлено. Основной workflow `SmartMaktab — подписанный релиз` по-прежнему требует доверенной подписи для EXE и ключи Android для APK/AAB.

## Получить установщик

1. Распакуйте ZIP обновления в корень локальной папки репозитория с заменой файлов. Сделайте Commit / Push в ветку по умолчанию. Репозиторий должен быть **приватным**; workflow в публичном репозитории остановится до checkout. GitHub создает личный артефакт с именем `PILOT-UNSIGNED`, не GitHub Release.
2. Для первой проверки только установщика можно пропустить этот шаг. Чтобы **этот же EXE** потом принимал пакеты без пересборки, задайте публичный ключ **до** запуска. Из корня проекта в PowerShell с Node.js (на компьютере того, кто будет подписывать содержимое):

   ```powershell
   node scripts/windows-content.cjs keygen "$env:USERPROFILE\SmartMaktab-content-private"
   ```

   Папка результата должна быть новой, вне репозитория и, желательно, на зашифрованном диске. Сохраните резервную копию `publisher.smupdate-key`; это **не** ключ APK и **не** подпись EXE. Не отправляйте его в GitHub, чат, админку или школьные ПК. Папку на Windows защитите правами NTFS. В `Settings → Secrets and variables → Actions → Variables` добавьте `SM_CONTENT_PUBLIC_KEY` = строка из `SM_CONTENT_PUBLIC_KEY.txt`.
3. Если нужна загрузка данных из GitHub при наличии интернета на ПК, **до первого выпуска** добавьте также `SM_CONTENT_FEED` = постоянный HTTPS-адрес вида `https://raw.githubusercontent.com/ВЛАДЕЛЕЦ/ПУБЛИЧНЫЙ_РЕПОЗИТОРИЙ_ДАННЫХ/main/latest.smupdate`. Подставьте свой реальный адрес. Это отдельное публичное хранилище **только общих материалов**, не школьных или личных данных. Автоматической публикации нет. Если хотите проверить только USB, переменную адреса не добавляйте.
4. `Actions → SmartMaktab — личный Windows Pilot (без подписи) → Run workflow`. Версия `1.0.0`, подтверждение `UNSIGNED`. Скачайте `SmartMaktab-Windows-PILOT-UNSIGNED-1.0.0` в Artifacts. Имя ярлыка — SmartMaktab Pilot; артефакт хранится 7 дней. Не смешивайте его с будущим официальным EXE.

## Проверка материалов без пересборки

1. Из корня репозитория:

   ```powershell
   node scripts/windows-content.cjs sign scripts/pilot-content.example.json "$env:USERPROFILE\SmartMaktab-content-private\publisher.smupdate-key" latest.smupdate
   ```

2. Либо скопируйте файл `latest.smupdate` с телефона через USB в папку компьютера, либо поместите **только** `latest.smupdate` по настроенному адресу GitHub. В пилотном кабинете директора: **Обновление материалов → Импорт файла с USB** или **Обновить из GitHub**. На офлайн-ПК пользователь сначала переносит файл стандартной «Передачей файлов»; кабель не запускает импорт сам. Программа проверяет Ed25519, поддерживаемую структуру и номер версии; затем показывает только настройки текущей должности. Просмотр не обращается в сеть; материалы доступны после перезапуска, без интернета.
3. Для второй редакции скопируйте JSON под новым именем, поменяйте `sequence` на `2` и измените текст. Упакуйте снова и замените опубликованный `latest.smupdate` (или перенесите по USB). Старый или повторный номер не принимается. Откат содержимого — перепубликация предыдущего текста **с новым большим номером**, без обхода проверки.

В первом пилоте доступны категории, подкатегории, четыре фиксированные иконки и текст для нескольких кабинетов. Пакет не может изменять код, запрашивать права или запускать файлы. DOCX и каталог учебников будут отдельными типами данных после проверки; нынешние шаблоны не подключены. Кнопка загрузки EXE на Android, `smartmaktab-admin` и обновление самого EXE в этот пилот не входят. Пакеты публичных материалов не содержат школьных/персональных данных и не заменяют серверную авторизацию.

Доступ к файлам — через системный выбор, а камера и микрофон — только для функции, которая их запросит. SmartMaktab не выдаёт себе права Windows, не просит доступ на первом старте и не готовит новые неиспользуемые разрешения. SQL в Supabase и ключи Android не затрагиваются.
