# SmartMaktab — прототип и контур Supabase Dev

**Актуальная поставка Windows / Android:** [инструкция по запуску и установке PWA](ЗАПУСК_WINDOWS_ANDROID.md).

**Текущий этап:** экран `dev/` и миграция RLS прошли сквозную проверку через локальные Supabase Auth и PostgREST на синтетических аккаунтах. Облачное подключение пока не настроено. См. [SUPABASE_DEV.md](SUPABASE_DEV.md) и [статус](IMPLEMENTATION_STATUS.md).

Откройте `index.html` в браузере или запустите локальный веб-сервер из этой папки. Прототип показывает интерфейс будущей программы, переключение таджикский/русский и дневной/ночной темы, демонстрационный селектор нескольких школ, разделы сотрудников, документы, планы, заседания, согласования и нормативные источники. Есть локальное сохранение в браузере, ручной экспорт/восстановление зашифрованной резервной копии кеш PWA-оболочки для повторного открытия офлайн и уведомление о готовом онлайн-обновлении с перезапуском.

Отдельно подготовлен [эксперимент согласования создания плана](PLAN_APPROVAL_EXPERIMENT.md). В 0.5 для него доступен двуязычный экран, только при явном включении на localhost. В 0.6 для той же песочницы добавлена [локальная очередь заявок](OFFLINE_OUTBOX_EXPERIMENT.md) с отдельным выключенным по умолчанию флагом. В 0.7 добавлено отдельно включаемое [чтение обновлений заявок между сеансами](FOREGROUND_APPROVAL_SYNC.md). Возможности стандартного Supabase Dev не меняются.

**Важно:** основной интерфейс `index.html` по-прежнему является локальным демо. Реальный вход и серверные права предусмотрены только в отдельном dev-контуре после его настройки. Настоящая межустройственная синхронизация, USB-обновление и производственные резервные копии не подключены. Данные демонстрационные и хранятся только в браузере; не заносите личные данные учеников/сотрудников.

## Этапы далее
1. Развернуть и проверить Supabase Dev по матрице доступа на тестовых аккаунтах.
2. Согласовать безопасность, обезличивание и процессы утверждения; добавить серверную запись через согласование.
3. Реализовать офлайн-хранилище и синхронизацию с разрешением конфликтов.
4. Проверить отдельный прототип USB-обновления и процедуру резервирования/восстановления.


## Предпросмотр для обсуждения интерфейса

Из `SmartMaktab_App`: `python scripts/preview.py`. Откройте `http://localhost:4180/`. Это текущий интерфейс: старт, 54 рабочих кабинета и ночной режим. Архивный дашборд и каталог не публикуются. Сервер **не публикует** конфигурацию Supabase, SQL или тесты. Для отдельной проверки Dev UI запустите исключительно на loopback `python scripts/preview.py --with-dev --port 4173` и смотрите [SUPABASE_DEV.md](SUPABASE_DEV.md).
