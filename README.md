# SmartMaktab

Рақамикунонии фаъолияти мактабҳо, шуъбаҳои маориф ва раёсатҳои маориф дар Ҷумҳурии Тоҷикистон.

## Иҷро ва санҷиши маҳаллӣ

- Сохтани саҳифаи оғоз (`index.html`): `python3 scripts/build_startup.py`
- Сервери пешнамоиши маҳаллӣ: `python3 scripts/preview.py --port 4180`
- Санҷиши тестҳои воҳидӣ ва пойгоҳи додаҳо: `npm test`
