# SmartMaktab · Windows и Android

**Формат поставки:** адаптивное веб-приложение (PWA) и его переносной HTML-вход в одном ZIP. Это не нативный установщик Windows и не APK. Распакуйте весь ZIP, а не запускайте файл прямо из архиватора.

## Windows

1. Откройте `START-WINDOWS.cmd` или `index.html` в актуальном Edge/Chrome. Интернет и Python для локальных экранов не нужны. В кабинете учителя сразу видны подходящие учебники; для открытия и скачивания публичных PDF нужен интернет. Читалка Kitobkhona и локальная «Алия» доступны прямо из `index.html` — устанавливать Python для них не нужно.
2. Для скачивания DOCX и системной печати используйте HTTP-режим: при установленных Python 3 и Edge/Chrome дважды щёлкните `START-FULL-WINDOWS.cmd`. Запускается сервер **только на этом компьютере** по адресу `http://127.0.0.1:4180/`. Оставьте окно командной строки открытым; `Ctrl+C` останавливает сервер. Команда вручную: `py -3 scripts\preview.py --open`.
3. При наличии пункта **«Установить приложение»** в Edge/Chrome можно установить PWA с `localhost` или из опубликованной HTTPS-версии. Для офлайн-открытия сначала дождитесь полной первой загрузки онлайн.

## Android

1. Для установки используйте **HTTPS-адрес** сервера, где опубликована распакованная статическая сборка; откройте его в Chrome → **«Установить приложение»** или **«Добавить на главный экран»**. ZIP сам по себе Android не устанавливает. `127.0.0.1` с ПК на телефоне не работает.
2. Дождитесь первой загрузки, затем приложение может открыть локальные кабинеты без сети. Подключение к интернету нужно для новых публичных PDF. Некоторые файловые менеджеры Android показывают HTML без JavaScript — для них используйте HTTPS/PWA, а не экран предварительного просмотра ZIP.
3. Рабочая область на телефоне прокручивается внутри текущего раздела; кнопка **«Назад» / «Бозгашт»** возвращает к предыдущему экрану.

## Что проверено

- «Оғоз»: браузер по HTTP, файловый запуск `file://` даже без `DecompressionStream`, изолированный файловый просмотрщик; сохранение выбранной школы, основной и дополнительных должностей.
- PWA: Chromium с размером и вводом Android (Pixel 7), загрузка ресурсов установки и перезапуск в принудительном офлайне. Физические устройства Windows/Android в этой проверке не использовались.
- Кабинеты: тесты 54 ролей, переходы в отдельные экраны, профили, расписание, сводные отчёты, DOCX, читалка и локальная «Алия». Проверена компактная ориентация ПК; длинные формы прокручиваются внутри рабочей области, а не всей страницы.

Записи прототипа остаются в текущей вкладке или в сеансе встроенного кабинета. **Нет** реальной авторизации для школьных данных, синхронизации устройств и USB-обновления. Используйте только вымышленные данные. В рабочем режиме не публикуйте `dev/`, `supabase/`, `tests/`, `scripts/` и файлы сборки: это исходники и локальные проверки, а не часть публичного сайта. Для обычной статической публикации достаточно `index.html`, `cabinets/`, `vendor/pdf/`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `pwa-192.png`, `pwa-512.png`.

Настройка опционального шлюза Kitobkhona: [АЛИЯ_ПОДКЛЮЧЕНИЕ.md](АЛИЯ_ПОДКЛЮЧЕНИЕ.md). В обычном запуске ключи не нужны.
