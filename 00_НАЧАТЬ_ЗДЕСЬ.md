# SmartMaktab — шаблоны v2 для будущей админки

Этот ZIP содержит 9 уникальных пар DOCX/JSON. В `templates/` файлы разложены по кабинетам; `00_Феҳрист.xlsx` — обновлённый перечень; `admin/catalog.draft.json` — заготовка структуры каталога и словаря для будущего импортера. `examples/` содержит исключительно вымышленные документы. Не загружайте эти примеры в рабочий каталог.

Пилотный DOCX из входного архива побайтно совпадал со справкой делопроизводителя. В новом наборе справка хранится один раз. В рабочем проекте уже существующий пилот не заменён.

Все формы — неутверждённые черновики. Связанные роли — только предложения, не права доступа. Этот пакет не изменяет APK/EXE, не включает готовую админку и не предназначен для автоматической публикации или импорта в действующий проект. SQL/Supabase не менялись.

Подробности по исправлениям — в `01_ОТЧЁТ.md`.
