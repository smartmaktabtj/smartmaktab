# Перенос функций из «Мактаби Муосир»

Просмотрен HTML `school_modern.html` из предоставленного архива. База SQLite со школьными записями не распаковывалась и не импортировалась. Старый сервер, вход, пароли, настройки среды, снимки камеры, госэмблема и файлы резервного копирования не переносились. Текущая интеграция является локальной: данные форм не сохраняются в школьной базе и не отправляются на сервер.

| Найденная функция | Что есть в SmartMaktab |
|---|---|
| `officialCertificateHtml` и список `certificateType` | Три вида маълумотнома: учащегося, для конкурса и для участия. Поля номера, даты, школы, класса, адресата, мероприятия и подписи; локальный предпросмотр и печать. Директор и делопроизводитель. |
| `printStudentCharacteristic` | Тавсифнома с описанием, поведением, достижениями и местом для подписей директора и руководителя класса. Не генерирует школьную характеристику из оценок. |
| `monitoringAverage`, `monitoringSummary`, `monitoringPeriodLabel` | Сводный отчёт по классу, предмету и периоду: четыре четверти, два полугодия и год. Доли считаются от списочного состава, как в источнике; пороги `>7` и `≥4` в форме поясняются, но не выдаются за норматив. Для средних используются `(Ч1 + Ч2) ÷ 2`, `(Ч3 + Ч4) ÷ 2`, `(П1 + П2) ÷ 2`; пропуск остаётся пропуском. Индивидуальных оценок и электронного журнала нет. |
| `scheduleList` | Печатный дневной список уроков одного класса: предмет, начало, конец, учитель, кабинет; сортировка и проверка пересечений. Не является расписанием, опубликованным для всей школы. |
| Библиотека, выдача книг и локальные электронные файлы | Учесть в следующем этапе после согласования полей, хранения и прав доступа. План библиотеки из SmartMaktab сохранён. |
| Достижения, объявления, школьная газета и учёт ученических объединений | Найдены; ещё не интегрированы. Сначала согласовать кабинеты, поля и условия публикации. |

Шаблоны не утверждены. До согласования доступа и хранения данных использовать только вымышленные записи.
